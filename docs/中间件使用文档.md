# FlashTicket 中间件使用文档

本文只列出本仓库实际使用的中间件，以及后端连接它们时的配置键。口令不在本文写出。密码一行只给出配置键名，或说明见本地配置、不要写入版本库。本地默认值若已存在于 `application.yml` 或 `docker-compose.yml`，以那些文件为准，不要把口令复制到新的文档、截图或提交说明里。

本地后端跑在宿主机，使用映射端口。`spring.profiles.active` 默认为 `local`（可用环境变量 `SPRING_PROFILES_ACTIVE` 覆盖）。生产 profile 为 `prod`，主机名改为 Compose 网络内的服务名，见各节「生产」行。

## MySQL

权威业务库。库名 `flashticket`，字符集 `utf8mb4`，排序规则 `utf8mb4_0900_ai_ci`，会话时区 UTC。镜像 `mysql:8.4`。JDBC 参数中的时区相关项以 `application.yml` 的 `spring.datasource.url` 为准。

| 项 | 值 |
|---|---|
| 本地 host | `127.0.0.1` |
| 本地 port | `33061`（映射容器 `3306`） |
| 生产 host | `mysql`（`application-prod.yml` 默认） |
| 生产 port | `3306` |
| database | `flashticket` |
| url 配置键 | `DB_URL`，对应 `spring.datasource.url` |
| username | 配置键 `DB_USERNAME`，对应 `spring.datasource.username` |
| password | 配置键 `DB_PASSWORD`，对应 `spring.datasource.password`。见本地 yml 或 `.env`，勿入库、勿写入本文 |

Compose 中的库口令环境变量名为 `MYSQL_ROOT_PASSWORD`。生产数据源密码在 `application-prod.yml` 中没有默认值，必须由 `DB_PASSWORD` 注入。

## Redis

用于刷新会话、邮箱验证码、滑动窗口限流，以及可选的库存准入快照。镜像 `redis:7.4`。库存与订单的权威数据在 MySQL，不在 Redis。

| 项 | 值 |
|---|---|
| 本地 host | `127.0.0.1` |
| 本地 port | `16379`（映射容器 `6379`） |
| 生产 host | `redis`（`application-prod.yml` 默认） |
| 生产 port | `6379` |
| host 配置键 | `REDIS_HOST`，对应 `spring.data.redis.host` |
| port 配置键 | `REDIS_PORT`，对应 `spring.data.redis.port` |
| username | 无。本地镜像未配置 ACL 用户名 |
| password | 配置键 `REDIS_PASSWORD`，对应 `spring.data.redis.password`。见本地 yml，勿入库。本地默认未设置口令 |

## RocketMQ

异步抢票、延迟关单和通知。镜像 `apache/rocketmq:5.3.0`。后端 v5 客户端只连接 Proxy 的 gRPC，不直连 Broker。

| 项 | 值 |
|---|---|
| 本地 endpoints | `localhost:8081` |
| 生产 endpoints | `proxy:8081`（`application-prod.yml` 默认） |
| endpoints 配置键 | `ROCKETMQ_ENDPOINTS`，对应 `rocketmq.producer.endpoints` 与 `rocketmq.push-consumer.endpoints` |
| NameServer port | 宿主 `9876`，容器内地址 `namesrv:9876` |
| Broker port | 宿主 `10911`，以及 `10909` |
| Proxy gRPC port | 宿主 `8081`，容器 `8081` |
| Proxy HTTP port | 宿主 `18080`，容器 `8080`（避开后端 `8080`） |
| username | 无。本地未开启 ACL |
| password | 无独立口令。访问键配置项为 `rocketmq.producer.access-key`、`rocketmq.producer.secret-key`，消费端同名键位于 `rocketmq.push-consumer`。本地为空字符串。若生产开启 ACL，用环境变量注入，勿写入本文 |

主题与配置键：

| 项 | 值 |
|---|---|
| 抢票主题 | 默认 `ft-purchase`，配置键 `ROCKETMQ_PURCHASE_TOPIC`，对应 `rocketmq.push-consumer.topic` |
| 关单主题 | 默认 `ft-order-close`，配置键 `ROCKETMQ_ORDER_CLOSE_TOPIC` |
| 关单 tag | 默认 `ORDER_CLOSE`，配置键 `ROCKETMQ_ORDER_CLOSE_TAG` |
| 通知主题 | 默认 `ft-notification`，配置键 `ROCKETMQ_NOTIFICATION_TOPIC` |

主题需预先创建，否则消费者报缺少路由。使用 `scripts/create-mq-topics.sh`，或 README 中的 `mqadmin updatetopic` 命令。集群名默认 `DefaultCluster`。

## Prometheus

抓取后端 Actuator。镜像 `prom/prometheus:v2.55.1`。配置文件 `docker/prometheus/prometheus.yml`。

| 项 | 值 |
|---|---|
| url | `http://localhost:9090` |
| host | `localhost`（容器内自监控目标为 `localhost`） |
| port | `9090` |
| username | 无。仓库中的 Prometheus 未配置基本认证 |
| password | 无。勿在 Prometheus 配置中新增口令后提交到仓库 |
| 抓取任务 | `flashticket-backend` |
| 抓取路径 | `/actuator/prometheus` |
| 抓取目标 | `host.docker.internal:8080`（后端在宿主机） |
| 抓取间隔 | `15s` |

后端本地 profile 通过 Actuator 暴露该路径。生产 profile 的 `management.endpoints.web.exposure.include` 只有 `health,info`，不对外暴露 Prometheus。

## Grafana

展示 Prometheus 数据。镜像 `grafana/grafana:11.4.0`。数据源与看板由 `docker/grafana/provisioning` 预置，看板标题为「FlashTicket 运营监控」。

| 项 | 值 |
|---|---|
| url | `http://localhost:3000` |
| host | `localhost` |
| port | `3000`（容器端口同为 `3000`） |
| username | 配置键 `GF_SECURITY_ADMIN_USER`，见 `docker-compose.yml` |
| password | 配置键 `GF_SECURITY_ADMIN_PASSWORD`，见本地 compose，勿入库、勿写入本文 |
| 注册 | `GF_USERS_ALLOW_SIGN_UP` 为 `false` |

## 相关配置文件

| 文件 | 作用 |
|---|---|
| `backend/src/main/resources/application.yml` | 本地默认连接与业务参数 |
| `backend/src/main/resources/application-prod.yml` | 生产 profile 覆盖 |
| `docker-compose.yml` | 本地中间件端口与镜像 |
| `docker/prometheus/prometheus.yml` | 抓取目标 |
| `.env.example` | 生产环境变量名示例，不含可用口令 |

JWT 私钥、`.env` 和 `application-local.yml` 的检查项见 `doc/密钥与敏感信息检查清单.md`。
