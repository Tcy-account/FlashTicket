# FlashTicket API 清单（M17-05）

> 生成时间：2026-10-16 · 由后端 `@RequestMapping` / `@*Mapping` 注解自动盘点整理
> 覆盖 16 个域、31 个 Controller、约 90 个端点。统一前缀 `/api/v1`，统一响应信封 `{code,message,data,requestId,traceId,timestamp}`。

**鉴权标记约定：**
- 🔓 公开（`permitAll`，仅 PUBLISHED/SCHEDULED 数据）
- 🔑 登录用户（Bearer JWT）
- 🛡️ 后台（Bearer JWT + `@PreAuthorize` 权限点，权限码 `{域}:{资源}:{动作}`）

## 附录：通用约定

- **分页**：列表接口统一返回 `PageResult{items,total,page,pageSize}`，请求参数 `page`/`pageSize`。
- **雪花 ID**：所有主键 BIGINT 雪花，前端以 **String** 传输（规避 JS 精度丢失）。
- **金额**：BIGINT 分，前端展示除以 100。
- **时间**：DATETIME(3) UTC，前端本地化展示。
- **错误码**：HTTP 管传输，`code` 管业务；领域码命名 `{域}_{含义}`（如 `PURCHASE_WINDOW_NOT_OPEN`）。
- **统一请求标识**：请求头 `X-Request-Id`（缺省自动生成），响应含 `requestId` + `traceId`。
